# References

Aquí van las capturas / GIFs / descripciones que el director sube como
referencia visual. Claude las consume para tunear feel, paleta, animación,
composición, etc.

Subir referencias así:

```
references/
  feel/         # Capturas de momentos: dash, jump, attack, hitstop, parry
  paleta/       # Colores que sí / no quieres
  composicion/  # Layouts de habitación, framing, escala
  arte/         # Concept art, mood boards
  anti/         # Cosas que NO quieres parecer
```

Para cada captura, **lo más útil es 1-2 frases de qué te llamó la atención**
en un archivo `.txt` o `.md` al lado. Sin descripción, la imagen sola me dice
poco — no puedo ver el movimiento, solo el frame.

Ejemplo:
```
references/feel/
  skul_dash_01.png
  skul_dash_01.md          ← "8 frames, recorre como 1.5x el ancho del char,
                              el polvo se queda atrás 3 frames más"
```
